# 🎉 Event Management System

A full-featured **Event Management System** built with **Django** that allows users to browse events, book tickets, submit reviews, and contact the event organizers through a clean and responsive web interface.

---

## 🚀 Features

* 🔐 User Authentication (Register, Login & Logout)
* 📅 Browse Upcoming Events
* 📖 Event Details Page
* 🎟️ Event Booking
* 📋 My Bookings
* ⭐ User Reviews & Ratings
* 📞 Contact Form
* 👨‍💼 Django Admin Panel
* 📱 Responsive Bootstrap Design

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/anandhuma10/Event-management-system.git
```

### Navigate into the project

```bash
cd Event-management-system
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

macOS/Linux

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Apply migrations

```bash
python manage.py migrate
```

### Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
